# Changelog

## 2.0.0

- Added IndexedDB-backed local storage with legacy migration, snapshots, and safe import validation.
- Added mobile navigation, settings, task details, interactive Markdown checklists, and keyboard help.
- Improved screen-reader support, offline update prompts, and first-run guidance.
- Split app features into vanilla JavaScript modules and added tests for storage migration and import validation.
- Added recurring tasks, task-note links, linked focus-time totals, expanded statistics, and editable sessions.
- Added a timer progress ring, sound controls, five-minute extension, and early session logging.
