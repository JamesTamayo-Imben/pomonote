# Contributing

Pomonote is a dependency-free vanilla JavaScript PWA. Keep changes small, preserve offline use, and avoid adding a build step or runtime dependencies.

1. Use Node.js 18 or newer.
2. Run `npm test` before submitting changes.
3. Run `npm start` and check the affected behavior at `http://localhost:3000`.
4. Include tests for changes to parsing, storage, or other pure helpers.

Please open an issue before proposing large features or changes to the local data format. Never include personal data or exported user backups in a pull request.
